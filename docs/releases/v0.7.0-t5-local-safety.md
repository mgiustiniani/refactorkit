## Historical relocation safety corrections

1. **Retain edits inside the moved source.** `TypeScriptCompilerServerClient`
   preserves every returned text change, including changes against the old path,
   and places those modifications before the structural rename. The existing
   import/export scenario now moves `src/a.ts` to `src/nested/renamed.ts`, checking
   the moved file's `../dep` import, a consumer import and a barrel re-export,
   exact text-edit coordinates, the complete post-image and untouched controls.
   The real compiler analyzes both immutable snapshots without modifying the
   original workspace. Test glue now reuses toolchain discovery rather than
   hardcoding an inaccurate Node version.
2. **Reject malformed replies as a whole.** The client requires boolean success,
   an array of complete file/text-change records, string paths/replacements and
   positive ordered integer coordinates. It no longer drops invalid entries or
   substitutes an empty result. Invalid results return
   `typescript.compilerServerResultInvalid` and stop the owned process before
   normalization. Valid empty arrays and empty replacement strings remain legal.
   One six-case outline extends the existing hostile-peer fixture and runner;
   two new expressions reuse the existing request and cleanup observations.
   These peers provide negative protocol evidence, never compiler authority.
