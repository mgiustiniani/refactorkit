## Safety boundary

All writes remain `PatchPlan` → explicit approval → operation-owned diagnostics
→ `PatchEngine`/WAL. Incomplete, stale, generated, plugin-dependent, ambiguous or
unsupported evidence refuses without edits. Public parameter-name changes require
explicit external-consumer-risk acceptance. Java positional calls are proven
against staged Kotlin output and retain the exact JVM owner/name/descriptor.

Extract/inline is intentionally much narrower than general data/control-flow
analysis: only a compiler-PSI-proven, top-level, zero-input integer expression is
accepted. Advanced shapes carry read-only facts and no mutation authority.
Delegated properties, Android, Multiplatform/`expect`/`actual`, generated/plugin
and framework-aware semantics remain typed refusals.
