- Overloads, literal `@JvmName`, extension/suspend/nested descriptor normalization and source primary/secondary constructors are covered.
- Primary-constructor `val`/`var` declarations retain separate parameter and direct-field property identities; FIR symbol kind disambiguates their shared PSI anchor.
- JDT projects exact non-recovered type/method/constructor/field identities and snapshot attestations.
- `SharedJvmIdentityProjector` joins exact tuples and emits bidirectional references without compiler handles or mutation authority.
- `BuildLanguageFacet` is additive, typed, hash-bound, bounded and ecosystem-neutral.
- JDT and K2 normalized results use bounded session-owned LRU state; provider snapshot drift refuses.
- `WorkspaceRefreshCoordinator` owns only scan/compare/prepare ordering; daemon, LSP and MCP retain lifecycle/protocol/write policy.
- The ten-row dependency boundary and `configured-unpublished` SPDX boundary are machine reconciled; they do not claim the final release SBOM.

## Native receipt contract

The dedicated `k1-k2-shared-foundations-native` CI job runs independently on Linux x86-64, Windows x86-64, macOS x86-64 and macOS arm64. Pull-request execution explicitly checks out and passes `github.event.pull_request.head.sha` to the finalizer rather than qualifying GitHub's synthetic merge commit. Each host:

1. checks out the exact source-head subject revision;
2. installs Temurin `21.0.11+10.0.LTS`;
3. runs the support verifier and its mutation tests;
4. runs the 14 required focused suites;
5. packages the self-contained runtime;
6. runs the descriptor-exact packaged Kotlin smoke;
7. emits a fail-closed revision/platform/JDK/support/report/package-hash receipt;
8. uploads evidence even when a preceding step fails.

A passing dedicated receipt is not a green whole-repository CI claim.
