# v0.7.0 K5 move-next acceptance

Status: local candidate; native four-platform qualification and independent review pending.

## Scope

This candidate implements only the sealed requirement in
`docs/requirements/kotlin-jvm-move-top-level-function-and-companion-refusal.md`
(SHA-256 `52dd7de86022e2d86e143c453fe2c445c2718149a6393d5ba462bbceb2642a0f`).

Qualified behavior, if the remaining gates pass:

- whole-file movement of one plain public top-level Kotlin/JVM function;
- exact K2 file-facade owner/name/descriptor and staged identity validation;
- one unaliased explicit Kotlin callable import per consumer file;
- package-token/import-token edits, one file rename, `PatchEngine` apply, WAL, diagnostics, and exact rollback;
- exact-JDT refusal of Java callable consumers;
- stable `kotlin.moveCompanionStandaloneUnsupported` refusal with no edit or transaction;
- unchanged already-qualified public top-level type/file movement.

Explicit non-claims include Java function callers, aliases, stars, same-package or
fully-qualified callable uses, callable references, overloads, extensions,
suspend/default/`@JvmName`/multifile forms, generated sources, compiler-plugin
semantics, declaration splitting, installed-runtime parity, and general Kotlin
managed support.
