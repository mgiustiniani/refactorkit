# RefactorKit 0.7.0 Java/Maven move-class authority acceptance

Status: the reported Magrathea CLI row is qualified locally on Linux/JDK 21.
The bounded source-built/in-process lexical-review boundary is also validated
across CLI, recipe, daemon-session, managed-LSP-session, and MCP-session paths;
the complete authority/refusal matrix, packaged runtime, and native platforms
remain open.

## Qualified safety boundary

Managed Maven `moveClass` apply remains available only with exact JDT binding
evidence. `LEXICAL_FALLBACK` is review-only and is rejected before workspace-lock
and WAL creation.

The target-scoped authority implementation now includes:

- a dependency-bounded reverse-observer closure;
- candidate-total `BOUND_TARGET`, `BOUND_OTHER`, and `UNRESOLVED` classification;
- exact Java target-name lookup protection;
- before/staged diagnostic and evidence identity;
- an operation-authority lease revalidated under the workspace lock;
- schema-v1 immutable `REVIEW_ONLY_GUIDANCE` for four safely enumerable Maven
  authority defects, with typed evidence groups and pre-lock/WAL CLI refusal;
- schema-v1 immutable `LEXICAL_FALLBACK_REVIEW` for broad legacy uncertainty,
  with deterministic non-capability identity, bounded edit-free residuals, and
  cross-surface refusal before plan/edit registration or managed-write entry;
- descriptor-closed traversal over selected Maven nodes;
- RefactorKit-owned evidence for a selected fixed ordinary Maven leaf whose POM
  closure is complete but JAR is absent; and
- typed structural refusal for missing, malformed, or drifted selected
  POM/parent/BOM/mediation/relocation evidence.

A dependency edge deterministically excluded by effective scope, transitive
optionality, or an exact inherited exclusion is pruned before child version,
repository, POM, JAR, or network lookup. If another path selects the same
coordinate, its complete effective descriptor closure becomes required again.

Offline discovery remains plugin-free, credential-free, and network-disabled by
default. No caller-attested classpath can grant authority.
