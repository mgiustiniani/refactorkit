== Decision Candidate Coverage

The ADR set covers patch safety, integration-surface and transaction-boundary classification, self-contained verifiable packaging, MCP least privilege, Eclipse JDT evidence-gated semantic authority, offline effective build models/source ownership, and the deferred supreme multi-language `1.0` target. ADRs 0003 and 0007 retain historical context but are superseded by ADR 0008. ADR 0009 supersedes the immediate post-`v0.3.0` Java-focused RC sequence without weakening any accepted safety decision. ADRs 0002 and 0004 record WAL-backed managed transaction guarantees, client-managed native LSP limitations, and the staged recipe-wide transaction boundary without claiming one filesystem-wide ACID commit. ADR 0010 separates package identity from module/source-set ownership, requires a shared Build Model SPI before deep JVM adapter expansion, and points to ADR 0012 for the qualified operation-specific use of `OFFLINE_MISSING` evidence. ADR 0012 keeps globally complete affected source sets as the stronger mode and permits the narrower target-scoped Maven `moveClass` proof only with global reactor/descriptor/candidate/platform/provider authority and closure-scoped missing-binary evidence. Implemented-and-validated REQ-JAVA-MAVEN-MOVE-AUTH-001 proves one complete-`AVAILABLE` binding-clean fixture flow: deterministic `JDT_BINDING` previews, zero-to-zero staged diagnostics, prohibited-activity denial, one exact staged-image transaction, after attestation, and exact rollback. Implemented-and-validated `002` proves the exact dependency-bounded direct/transitive/test-only observers, keeps the sole exact `BOUND_OTHER` decoy distinct from one Java string-literal residual occurrence and two non-Java residual paths, selects no residual edit, and restores the full non-engine workspace exactly after one apply/rollback. Requirements `007`, `009`, `010`, `011`, and six-case `012` remain independently bounded evidence for their missing-binary, scope, pruning, ordinary-absence, and selected-descriptor shapes; `003`, `004`, and `008` remain absent. Dated field evidence separately qualifies only one Magrathea request at consumer commit `a48e3c06` through the source-built CLI on Linux/JDK 21 after `010`; neither the fixture rows nor that request establishes integration/native-matrix or general support.
