= 2. Architecture Constraints
:toc:
:sectnums:

Status: implementation-informed, with a confirmed P0 target-scoped Maven move-class authority priority; needs-review for remaining priority and completeness. Eleven bounded Maven move-class requirement definitions expanding to sixteen cases are implemented and validated. REQ-JAVA-MAVEN-MOVE-AUTH-001 validates the complete-`AVAILABLE` binding-clean positive row. REQ-JAVA-MAVEN-MOVE-AUTH-002 validates the exact binding-selected observer boundary: direct `catalog-pricing:main`, transitive `catalog-storefront:main`, and test-only `catalog-acceptance:test`, with exact candidate/residual discrimination and rollback. REQ-JAVA-MAVEN-MOVE-AUTH-003 validates four independently isolated, safely enumerable default-scanner defects that return deterministic immutable Java-specific guidance with schema/checklist version 1, typed evidence, JSON CLI output, and `guidance.nonManaged` CLI apply refusal before `PatchEngine`, lock, or WAL. REQ-JAVA-MAVEN-MOVE-AUTH-004 validates the distinct schema-v1 `LEXICAL_FALLBACK_REVIEW` outcome through the Java move-class operation dispatcher, source-built CLI, recipe engine, daemon session, managed LSP session, and MCP session, including edit-free protocol projection, typed known-operation refusal, and exact non-mutation. Existing evidence also covers CLI lexical-fallback refusal without residue (`005`), the `AVAILABLE` warning boundary (`006`), synthetic closure-missing `OFFLINE_MISSING` apply/rollback (`007`), explicit transitive-test-scope preservation (`009`), descriptor-closed selector pruning and alternate selected-path missing-POM refusal (`010`), ordinary sidecar-free selected-JAR absence with under-lock drift refusal (`011`), and six selected-descriptor refusals (`012`). Only the six-case structural-loss/post-preview-drift outline `008` remains absent. Separately, the exact Magrathea request at commit `a48e3c06` remains CLI-qualified only on Linux/JDK 21 after `010`; REQ-004 does not add packaged-process, runtime-distribution, native-platform, or general move-authority qualification.

|C-TECH-025
|A legacy Java/Maven `moveClass` compatibility preview with `LEXICAL_FALLBACK` is projected by the Java move-class operation outcome dispatcher as one immutable schema-v1 `LEXICAL_FALLBACK_REVIEW`. The envelope reports `semanticCompleteness=NOT_SEMANTICALLY_PROVEN`, `authorityStatus=REVIEW_ONLY`, `evidenceKind=LEXICAL_FALLBACK`, `managedWriteEligibility=INELIGIBLE`, and `blockerCode=evidence.insufficient`. Canonical JSON hashing supplies `requestSha256`, exact `snapshotSha256`, hidden `reviewArtifactSha256`, sorted-fact `evidenceSha256`, and deterministic non-capability `operationId=lexical-review-<sha256>`. The hidden review-artifact hash commits to normalized internal compatibility file operations, exact edit ranges, and replacement/create byte hashes; none of those ranges or bytes is exposed. Exposed residual records contain only normalized path, current content SHA-256, typed risk facts, and `managedEdit=false`. They are bounded to 200 records and 262,144 canonical UTF-8 record bytes, report `recordCompleteness=COMPLETE or TRUNCATED`, deterministic returned-category counts, and fixed next actions. No envelope contains a protocol plan/edit/range/replacement/apply token, pending managed plan, LSP `changes`/`documentChanges`, transaction, or rollback capability. The Java-owned LRU audit cache holds envelopes only, is capped at 128 entries/16,777,216 canonical bytes, and is cleared on relevant project, snapshot, mutation, semantic-session, initialization, and close lifecycle changes. Daemon, LSP, and MCP share `RefactoringApplyIdentity.parse`, which requires exactly one non-blank `operationId` or `planId`: a known operation returns typed `evidence.insufficient`; unknown or evicted operations and arbitrary plans return `INVALID_PARAMS`. Daemon/LSP JSON-RPC preserve structured error `data`; MCP returns equivalent structured error content. Recipes return the lexical envelope immediately without an aggregate, and a clean full-reactor JDT preview still returns the existing eligible managed `Plan` outcome.
|ADRs 0002, 0004, 0008, and 0012; `JavaMoveClassLexicalFallbackReview.kt`, `JavaMoveClassLexicalFallbackReviewJsonProjection.kt`, `JavaMoveClassOperationDispatcher`, `RefactoringApplyIdentity`, CLI/recipe/daemon/LSP/MCP handlers, and `JavaMavenMoveClassLexicalFallbackReviewCucumberTest`; implemented-and-validated REQ-JAVA-MAVEN-MOVE-AUTH-004.
|implementation-informed for the bounded source-built/in-process cross-surface scenario; no packaged-process, runtime-distribution, native-platform, or general-authority qualification

|C-BOUND-001
|Frontend/UI technologies are out of scope for this repository.
|`AGENTS.md` scope and non-goals.
|implementation-informed

|C-BOUND-002
|LSP is for editor-native features; advanced AI workflows use JSON-RPC or MCP instead of overloading LSP. |C-BOUND-003
|MCP must expose deterministic tools and focused resources, not arbitrary filesystem access.
|`docs/integration-contracts.md`, `docs/ai-workflow.md`.
|implementation-informed

|C-BOUND-004
|C2 containers in the C4 model represent runtime entry points or intentionally separable building blocks; current library modules are not necessarily standalone deployables.
|`docs/c4/workspace.dsl`.
|implementation-informed

|C-BOUND-005
