== Technical Debt from Release Plan

The active stable plan defines the remaining release-hardening workstreams:

* `v0.4.0` and `v0.5.0` are published; `v0.6.0` adds the accepted managed TypeScript/JavaScript semantic foundation while retaining API `0.2`;
* keep API `0.2` active until normative patch/apply/rollback and API `1.0` CLI/daemon contracts are frozen and accepted;
* prove Eclipse JDT source compliance and semantic boundaries for Java 8 through Java 25;
* preserve the closed TX-001 through TX-018 qualified transactionality evidence during API freeze;
* retain precise qualification for WAL-backed managed transactions, the staged recipe-wide boundary, client-managed native LSP edits, and unsupported/destructive filesystem failure models;
* complete the planned product-critical `RPK-JAVA-DIAG-001..007` authority epic before treating Java/Maven diagnostics as definitive, including full-reactor/source-set environments, exact release signatures, non-executable discovery, exact deltas, typed JPMS refusal, and native packaged fixtures;
* preserve implemented REQ-JAVA-MAVEN-MOVE-AUTH-001/005/006/007/009/010/011/012, including the bounded complete-`AVAILABLE` positive row and all six inherited selected-descriptor cases; close the remaining P0 gap with `002` observer discrimination, `003` non-managed guidance, `004` cross-surface refusal, and six-case `008` uncertainty/drift acceptance; retain the Magrathea `a48e3c06` CLI/Linux/JDK-21 result as bounded field evidence and require explicit integration/native matrices before broader qualification;
* complete diagnostic regression gates and representative project acceptance;
* classify and test stable LSP/MCP boundaries;
* establish bounded performance and resource behavior;
* verify self-contained assets with checksum, SBOM, provenance/attestation, and reproducibility evidence;
* retain `TD-DIST-001` as explicit platform-signing debt until protected Apple Developer ID/notarization and Windows Authenticode credentials exist; unsigned assets must continue to disclose possible OS publisher warnings;
* promote only an RC with no unresolved release blocker.

Status: confirmed long-range target from `docs/releases/v1.0.0-plan.md` and ADR 0009; `v0.3.0` publication and downloaded-runtime smoke evidence are implementation-informed, `v0.4.0` acceptance is complete, and multi-language/stable acceptance remains pending.
