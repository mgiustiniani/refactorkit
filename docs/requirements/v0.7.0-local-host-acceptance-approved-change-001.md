preview/approval, PatchEngine-managed writes, WAL and exact rollback remain

identity, checksums, provenance and integrity checks for assets actually shipped
remain required; verification does not require repeating the waived host matrix.
No release publication, installation replacement or unrelated scope expansion is
authorized by this change.
