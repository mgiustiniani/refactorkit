  no wildcard version, accepted-version fallback, case-set change, requirement-pin
  rewrite or new receipt framework is authorized by this record.

  remains restricted to0.7.0: Linuxx86-64 only for this release's build policy;

  launch the old four-host matrix forv0.7.0. This does not waive source/asset/native

Metadata reconciliation is not a newly discovered algorithm defect and must not
be represented as a product RED. Every actual defect still requires its own
requirement-bound genuine RED and correction. Historical snapshot evidence stays
on its original inputs; the release version requires distinct artifact identity
and execution/review joins before publication.
